# UI provenance

Art direction: original cream/ink/ochre industrial operations workbench; preserve existing product layout. Motion Primitives TransitionPanel imported from https://github.com/ibelick/motion-primitives/blob/main/components/core/transition-panel.tsx (MIT, author ibelick). Changes: remove Next.js-only use-client directive, replace app-specific cn alias with local class join, useReducedMotion disables vertical movement and sets duration zero. Source copied through GitHub connector on October 14. Motion runtime 12.23.24 pinned.

Realtime Colors palette exploration: https://www.realtimecolors.com/?colors=17254b-f8f7f2-193aaf-e9edf8-a9471e . Named color roles are exported as CSS tokens for ProofHarbor; Loadstone retains its accepted palette. Haikei SVG generation is only used if actual access/export succeeds; original cover/chart assets are not claimed to be Haikei output.
