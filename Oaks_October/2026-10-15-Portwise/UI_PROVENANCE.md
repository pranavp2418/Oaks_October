# UI provenance

Motion Primitives: actual current upstream TransitionPanel source was read at https://github.com/ibelick/motion-primitives/blob/main/components/core/transition-panel.tsx. src/transition-panel.tsx reuses the collection’s equivalent adaptation (local class join instead of a framework alias). Original component/notice retained. Reduced-motion preference removes panel travel and duration.

Palette: original signal-console colors #101d2c / #f0e5cc / #edbb5a / #172b3a / #b95b44. Official Realtime Colors site and Haikei site/pricing were fetched; no palette export or generated Haikei asset is claimed at this checkpoint. The connection diagram and cover are original source-bound SVG/CSS rather than generic generated shapes.

Fonts: Google-hosted Manrope and Barlow Condensed with system fallbacks. No font binaries redistributed in this product. Formal font-license/source and color-export review remain release tasks.
