# Portwise acceptance contract — pending implementation

A synthetic integration-support agent investigates failed webhook connections and proposes the least-risk configuration repair. It operates only on bundled synthetic connectors, never external customer systems.

Core: finite typed configuration constraints with weighted minimal-change repair, immutable secret placeholders, counterfactual replay of delivery fixtures and unsatisfiable constraint explanations. Differential verification against exhaustive assignments. Unlike earlier retry simulators, this product repairs incompatible configuration under field-level authorization and proves that regression fixtures remain valid.

Connected capabilities: versioned connector/fixture import; persisted support cases; bounded LangGraph tool investigation with actual validated tool I/O; human-reviewed configuration patch; staged replay, failure/retry/rollback; signed-by-hash evidence export; repair/regression/queue operational inspection. Node/Express/TypeScript and React, meaningful LangChain tools. No arbitrary network or shell tools. The same exact patch hash and base revision must pass review and apply; stale or changed patches fail closed.
