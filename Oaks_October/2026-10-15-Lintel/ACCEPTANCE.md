# Lintel acceptance contract — pending implementation

A synthetic construction-permit readiness agent helps a project coordinator identify missing evidence, evaluate alternatives, and review a version-bound submission dossier. It never contacts authorities or claims legal advice.

Core: typed AND/OR prerequisite compiler; enumerate minimal missing-evidence frontiers, calculate dependency critical paths and deadline slack, detect cycles and contradictory evidence, and recompute version-specific impact after changes. Compare frontiers against an independent powerset oracle on bounded generated cases.

Connected capabilities: schema-validated document/evidence import; persisted project and requirement revisions; goal-driven read-only investigation through real LangGraph/LangChain tools; human-reviewed dossier preparation with stale-version fencing; failed/retried/interrupted investigations and checkpoint recovery; traceable evidence exports; dependency/slack/operational inspection.

Storage: SQLite local transaction journal plus durable graph checkpoints. Hosted single-user workspace must survive reload/export/restore; no multiuser or remote-database claim unless independently implemented. A Vercel Python API executes the actual compiler and agent; Angular is the operator UI. Model calls must check live catalog zero prices and reject paid fallback. Tool output is untrusted evidence; agent cannot submit, approve or execute arbitrary code.

Seven-axis scorecard: core/oracle, persistence/schema/transactions, API/tool contracts, recovery/adversarial paths, reproducible bounded evaluation, complete accessible workflow, clean build/live identity/recovery are all PENDING. No axis passes from this document.

Verification before release: generated oracle cases, cyclic/unknown/oversized input, contradictory/expired evidence, idempotent and conflicting imports, stale approval, restart, concurrent writers, model/tool failures/injection, desktop/mobile/keyboard/reduced-motion flows, clean lockfile install, pushed-source deployment correspondence, real workflow capture and editorially reviewed launch film.

Art direction: architectural drawing desk; warm limestone, ink, vermilion; large editorial headings; prerequisite graph and paper dossier split view; purposeful fold/reveal motion.
