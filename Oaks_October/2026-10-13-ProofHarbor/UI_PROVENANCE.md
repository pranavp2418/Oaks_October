# UI provenance

Original editorial incident-dossier layout: Newsreader headings, DM Sans controls, paper/cobalt palette, persistent evidence rail and source-path inspector. Angular uses native transform/opacity section choreography (.24s) with reduced-motion alternatives; no React dependency was inserted solely for Motion Primitives. Loadstone uses the actual upstream TransitionPanel component.

Realtime Colors was opened with the actual five-role palette: https://www.realtimecolors.com/?colors=17254b-f8f7f2-193aaf-e9edf8-a9471e&fonts=Inter-Inter . Paper, text, primary, secondary and accent colors were inspected in its live template, then retained as CSS tokens; the application's typography is independently selected Newsreader/DM Sans. No Realtime Colors source code or proprietary design assets were copied.

Haikei: public/haikei-evidence-steps.svg was generated/exported through https://app.haikei.app/ using Layered Steps, background F8F7F2 and fills E9EDF8/DDE4F8, three layers and the displayed default shape controls. It supplies a restrained layered-evidence motif for the empty investigation desk. Actual exported SVG retained unchanged. Terms/license references: https://haikei.app/terms/ and https://haikei.app/pricing/ . Other cover/diagram graphics are original, not Haikei exports.

Motion uses immediate input feedback, short section transitions, a bounded progress indicator, keyboard-focus rings and reduced-motion CSS. No background animation loop, GPU scene or chart dependency. Angular AOT removes the browser compiler: initial application bundle 197.62 kB raw / estimated 55.27 kB transfer at the recorded build before the SVG asset addition. Google Fonts use system/Georgia fallbacks if external font download is unavailable.
