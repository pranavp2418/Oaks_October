# Product art direction and provenance

Audience: engineers comparing finite protocol contracts. Direction: a dark bench instrument with cyan current-state traces and amber fault markers; horizontal workflow rail, graph/step table and repair sheet rather than dashboard-card collage. Typography: local system sans and monospace; no redistributed font binary. A4 rhythm, compact8px spacing grid, visible focus outlines and native form controls.

Actual Realtime Colors palette/export workflow: https://www.realtimecolors.com/?colors=f0f3ef-12191e-60ddd0-203137-ffb75a&fonts=Inter-Roboto%20Mono . Tokens are text#f0f3ef,background#12191e,primary#60ddd0,secondary#203137,accent#ffb75a. Palette commercial use checked in its current FAQ. Final system fonts are fallbacks, not downloaded typefaces.

Native TypeScript/DOM UI uses equivalent native motion:140ms opacity/transform transitions, coordinated selection/feedback and an explicit reduced-motion control plus prefers-reduced-motion. No React component dependency is added to this Go/native-DOM product. Motion Primitives current transition-panel source/MIT reviewed for the trio's React products; no Motion Primitives component use is claimed here. Haikei's current free SVG/commercial license was reviewed; exact protocol graph/cover geometry is original code-native SVG, not a Haikei export. No arbitrary decorative blobs.

The real Go WASM core runs in a worker. Charts have equivalent semantic tables. Operational measurements distinguish solver work, actual input samples and bundle sizes; wrapper frame timing is not called device FPS. Browser screenshots, narrow layout, keyboard/failure flows and measured costs are retained in the release QA report after they are checked.
